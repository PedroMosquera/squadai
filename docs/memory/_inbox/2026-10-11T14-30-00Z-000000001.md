Budget hooks (2026-10-11): apply writes `squadai budget-hook --event <name>` entries into .claude/settings.json when usage.enforcement is warn, ask or block and a token budget is set. block/ask install PreToolUse, UserPromptSubmit and Stop (onFailure block only under block); warn installs UserPromptSubmit and Stop. A block is exit 2 with the reason on stderr. Stop never blocks, because a Stop block keeps Claude working. Commands with the `squadai budget-hook ` prefix are squadai-owned: rewritten and pruned on apply, while user hooks are only added to, and HookEntry keeps unmodeled fields (if, args, statusMessage). PreModelSwitch is skipped because usage has no tier ceiling. ccusage is not read: the internal reader already parses the same JSONL without a Node startup.
