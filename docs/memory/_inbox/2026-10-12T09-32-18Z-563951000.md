Shared-file ownership (2026-10-12): opencode.json and .claude/settings.json are written by several components (permissions, MCP, plugins, hooks). Any component that records managed keys must merge with the keys already in the sidecar, never replace the list; the permissions installer did replace it and silently dropped MCP and plugin ownership until 1d97d74. Pi/OpenCode plugin packages are owned as exact strings in managed_entries; user entries keep their position and a user entry for the same package at another version is a conflict.
